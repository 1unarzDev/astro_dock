BOAT COMMANDS

Build
  colcon build --packages-select mhseals_nav mhseals_hardware  # the shell reloads itself

Launch
  ros2 launch mhseals_nav robot.launch.py sim:=true
  ros2 launch mhseals_nav robot.launch.py sim:=false sensors_ignore:=camera,lidar fcu_url:=serial:///dev/ttyACM0:57600  # ODROID
  ros2 launch mhseals_nav sensors.launch.py sim:=false  # Jetson sensor host
  ros2 launch mhseals_nav robot.launch.py --show-args   # all launch options

Manual control / tests (ODROID)
  ros2 run mhseals_hardware thruster_pwm_node
  ros2 run mhseals_hardware keyboard_control  # WASD/arrows; Space neutral; X exit
  ros2 run mhseals_hardware thruster_test
  ros2 run mhseals_hardware boat_test         # guided tests + sensor bags
  Secure boat/clear propellers; run one command publisher at a time.
  PWM takes effort, not Nav2 velocity; use a calibrated controller between them.

Monitor
  ros2 topic echo /mavros/state
  ros2 topic hz /points
  ros2 run rqt_tf_tree rqt_tf_tree
  rviz2
  ros2 launch rosbridge_server rosbridge_websocket_launch.xml  # ws://<host>:9090

Settings / details
  Hardware overrides: ~/.config/mhseals/hardware.yaml
  Hardware options: ros2 run mhseals_hardware boat_test --help
  Navigation and objects: src/mhseals_nav/docs/
  Container setup and compatibility: README.md
